مجموعة من خلاصات RSS للمسلسلات الإذاعية التاريخية والبرامج الصوتية المنشورة من إذاعة دمشق.

## 📱 How to Subscribe | طريقة الاشتراك

The RSS feeds can be added to podcast applications such as AntennaPod.

يمكن إضافة خلاصات RSS إلى تطبيقات البودكاست مثل AntennaPod.

1. Copy the RSS feed URL.
2. Open your podcast application.
3. Select Add Podcast or Add RSS Feed.
4. Paste the URL and subscribe.

1. انسخ رابط RSS.
2. افتح تطبيق البودكاست.
3. اختر إضافة بودكاست أو إضافة رابط RSS.
4. الصق الرابط واشترك.
